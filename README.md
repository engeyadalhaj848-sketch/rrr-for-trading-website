# R R R for Trading Website

الموقع الرسمي التجريبي لشركة **آر آر آر للتجارة** في المدينة المنورة.

## النشاط

- توريد الجبس بورد وملحقاته
- بدائل الرخام والخشب
- مواد ومنتجات التشطيب

## التطوير المحلي

الموقع ثابت وموجود داخل مجلد `dist`.

```bash
python3 -m http.server 4173 --directory dist
```

ثم افتح `http://localhost:4173`.

## النشر

تم تجهيز `vercel.json` بحيث تنشر Vercel محتويات مجلد `dist` مباشرة.
